# CMCP 4.24.3

- Windows 主界面打开即可立即操作，后台服务初始化期间不再全局禁用控件；初始化期间点击连接的操作会在后台就绪后无缝接续执行，同时大幅压缩后台冷启动与热复用耗时。
- Windows、Mac 和 Linux 三端从系统托盘／菜单栏点击“退出程序”均立即隐藏托盘图标与窗口（若停机异常可自动恢复提示），并消除三端本机文件服务与 SSH 工具通道退出时的子进程超时空等，显著加快程序退出速度。

On Windows, the main window is immediately interactive on launch without locking controls while the local service starts, seamlessly queuing early connection clicks and speeding up backend startup. Across Windows, macOS, and Linux, exiting from the system tray or menu bar hides the tray icon immediately and eliminates child-process shutdown wait timeouts across local file services and SSH tool channels.

## Windows、Mac、Ubuntu 统一版本

- Windows：ClaudeWeb 独立版或自行安装的 CloudCLI 的设备，点击“连接”后会在连上时自动打开浏览器并登录，与 WebDesktop 以及 Mac、Ubuntu 版一致。之前只显示“已连接”，需要再点“打开 ClaudeWeb”。
- Windows：停止状态下点击“打开 ClaudeWeb”不会再打开两个页面。
- Mac、Ubuntu 只更新版本号，与 Windows 保持一致。

## 升级

- Windows、Mac，以及 Ubuntu 4.23.3 及以上，可在「设置 → 关于」检查并安装更新；Ubuntu 4.23.2 可用本页的 `CMCP-4.24.1-linux-x64.deb` 升级。

## Windows, Mac and Ubuntu on one version

- Windows: for standalone ClaudeWeb or a self-installed CloudCLI, Connect now opens the browser signed in once the connection is up, as WebDesktop and the Mac and Ubuntu versions do. Before, the card only showed "connected" and you had to click "Open ClaudeWeb".
- Windows: clicking "Open ClaudeWeb" on a stopped device no longer opens two pages.
- Mac and Ubuntu only take the new version number.

## Upgrading

- Windows, Mac, and Ubuntu 4.23.3 or later can check for and install the update in Settings > About; Ubuntu 4.23.2 can upgrade with `CMCP-4.24.1-linux-x64.deb` from this page.

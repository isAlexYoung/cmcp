## Ubuntu x64 专版

- 修复 Ubuntu 应用菜单和任务栏显示默认图标的问题。
- 修复共享网页连接完成后，Claude MCP 配置因要求 Linux 截图工具而失败的问题。新日志会记录配置失败的阶段和退出码。
- 为 Claude Desktop 和 Claude Code 注册 `linux-pc-files`。重新连接后，重启云端 Claude 以加载配置。通过 `linux_execute` 使用本机 Bash，文件操作遵循已配置的本机目录。
- 应用内更新按 Linux x64 选择可用的稳定版本，支持跳过其他平台的专版。

Ubuntu 4.23.2 用户请安装本页的 `CMCP-4.23.3-linux-x64.deb`，应用菜单图标也会随安装更新。Windows 和 macOS 的当前稳定版本仍为 4.23.2。

## Windows、Mac、Ubuntu 统一版本

- 支持 ClaudeWeb 独立版：CMCP 自动识别 VPS 上运行的是 WebDesktop 内置的 ClaudeWeb、ClaudeWeb 独立版，还是自行安装的 CloudCLI。WebDesktop 内置 ClaudeWeb 的连接方式不变。
- ClaudeWeb 独立版自动登录：打开自动登录后，CMCP 用保存的密码向 ClaudeWeb 换取一次性登录码（两分钟内有效，只能用一次），打开网页即已登录，密码不会出现在网址里。已有其他设备登录时，网页会询问“加入”还是“接管”。保存的密码不对或登录被暂时锁定时，网页改为手动输入，设备卡片上会说明原因。
- ClaudeWeb 独立版的本机工具经此设备的 SSH 后台通道连接。“初始化／修复 ClaudeWeb 连接”能识别独立版（claudeweb 服务和用户），不会另装 Claude CLI，并提示用 `claudeweb password` 查看登录密码。
- 界面中的“CloudCLI”统一改称“ClaudeWeb”；专指上游原版时仍写“自行安装的 CloudCLI”。

## 升级

- Windows、Mac，以及 Ubuntu 4.23.3 及以上，可在「设置 → 关于」检查并安装更新；Ubuntu 4.23.2 可用本页的 `CMCP-4.24.0-linux-x64.deb` 升级。
- 自动登录需要 VPS 上的 ClaudeWeb 独立版提供 CMCP 登录接口。较早的 CMCP 连接独立版时按“自行安装的 CloudCLI”处理，需在网页手动输入密码。

## Windows, Mac and Ubuntu on one version

- Standalone ClaudeWeb is supported: CMCP tells apart the ClaudeWeb inside WebDesktop, standalone ClaudeWeb, and a self-installed CloudCLI. The WebDesktop connection is unchanged.
- Automatic sign-in for standalone ClaudeWeb: CMCP trades the saved password for a one-time code (valid two minutes, used once), so the page opens signed in and the password never appears in the address. When other devices are signed in, the page asks whether to join or take over. A wrong saved password or a temporary lockout falls back to typing the password, and the device card says why.
- Local tools for standalone ClaudeWeb go through the device's SSH background channel. "Set up / repair ClaudeWeb connection" recognises it, installs no second Claude CLI, and points to `claudeweb password` for the login password.
- "CloudCLI" is now called "ClaudeWeb" in the interface; "self-installed CloudCLI" still names the upstream project.

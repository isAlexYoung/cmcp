## Ubuntu x64 专版

- 「设置 → 关于」会列出缺失的桌面工具依赖。点击「安装依赖」并通过 Ubuntu 系统授权，可补齐 X11 键鼠所用的 `xdotool` 或托盘菜单所用的 `gir1.2-dbusmenu-glib-0.4`。应用更新本身仍可独立安装。
- 修复断开设备连接后，CMCP 启动的 Chrome／Chromium 独立窗口有时未关闭的问题。关闭范围限于该连接使用的独立浏览器配置。

## 升级

- Ubuntu 4.23.3 和 4.23.4 可从「设置 → 关于」检查、下载并安装更新。升级保留同一 Ubuntu 账号下的设备配置和密钥环密码。
- Ubuntu 4.23.2 可用本页的 `CMCP-4.23.5-linux-x64.deb` 升级。
- Windows 和 macOS 的稳定版本仍为 4.23.2。

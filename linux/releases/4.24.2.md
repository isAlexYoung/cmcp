# CMCP 4.24.2

- Windows 不再强制限制命令及其子进程的内存，也不再为 Node 命令注入堆内存上限。Mac 和 Linux 保持没有 CMCP 内存上限的行为。
- Windows、Mac 和 Linux 均可通过独立版 ClaudeWeb 2.1.5 的网址连接本机 MCP 工具，不需要另一条 SSH 连接。浏览器和工具共用登录会话，断开时只结束本连接的会话。
- 保留三平台 SSH 连接。root SSH 连接独立版时，自动将连接器注册到 ClaudeWeb 用户的配置；显式选择的用户和 WebDesktop 共存版的共享会话保持原有路径。
- 更新 CMCP 和独立版 ClaudeWeb 后，重新连接设备并开始新对话。

Windows commands and their descendants no longer have CMCP-imposed memory caps or an injected Node heap limit. Mac and Linux remain uncapped by CMCP. All three clients support standalone ClaudeWeb 2.1.5 URL-based PC MCP connections without a separate SSH channel, sharing one login session with the browser. SSH remains supported, including automatic selection of the standalone service account for root logins.

## Ubuntu x64 专版

- 新增 GNOME 托盘。可在托盘查看设备状态、连接、断开、重命名、切换登录方式、打开主界面和退出。启用「关闭时最小化到托盘」后，关闭窗口会保留后台连接。
- 补齐 Windows 基础 MCP 工具的 Linux 对应项。新增本机截图、鼠标点击、中文输入、快捷键和浏览器打开，截图支持按显示器或区域保存到授权目录。截图和键鼠目前支持 X11。
- 扩充后台任务及开发工具。支持后台 Bash、独立和增量的 stdout/stderr、stdin 输入、工具链检测及按设备序列号调用 ADB。Blender 工具可在「设置 → 工具」启用。

## 升级

- 已装有 `gir1.2-dbusmenu-glib-0.4` 和 `xdotool` 时，Ubuntu 4.23.3 可从「设置 → 关于」直接更新。若缺少新依赖，请安装本页的 `CMCP-4.23.4-linux-x64.deb`，由 apt 安装依赖。GNOME 托盘使用 Ubuntu AppIndicators。
- 仍在 Ubuntu 4.23.2 的用户可以直接用本页的 `.deb` 升级。使用同一 Ubuntu 账号可继续访问原设备配置和系统密钥环。
- Windows 和 macOS 的稳定版本仍为 4.23.2。

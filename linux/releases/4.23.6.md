## Ubuntu x64 专版

- 修复 Ubuntu 22.04 GNOME 下，CMCP 启动非 Snap 版 Chrome／Chromium 或 Edge 时因 Secret Portal 卡住而无法打开网页的问题。新窗口通过系统密钥环读取加密密钥，使用独立配置并保留原浏览器配置。首次打开可能需要重新登录网页。
- 「设置 → 通用 → 访问权限」新增「管理员操作（逐次授权）」，默认关闭。开启后，Claude 可请求读取本机内核警告和错误，或安装 `lm-sensors`、`adb`、`nodejs`、`npm`、`docker.io`。每次操作都需在本机确认并通过 Ubuntu 授权。设置页用红字说明日志回传和系统变更的风险。

## 升级

- Ubuntu 4.23.3 及以上可在「设置 → 关于」检查并安装更新。升级保留同一 Ubuntu 账号下的设备配置和密钥环密码。
- Ubuntu 4.23.2 可用本页的 `CMCP-4.23.6-linux-x64.deb` 升级。
- Windows 和 macOS 的稳定版本仍为 4.23.2。

# CMCP Ubuntu 版工作目标

创建日期：2026-11-17。状态：第一阶段与界面内更新已实现，Ubuntu 22.04.5 / WSL2 下运行、打包、安装、GTK / WebKit、更新重启和独立密钥环测试通过；双系统原生 GNOME / X11 与真实云端连接尚待验收。实现清单与实机验收分别记录。

## 目标与支持边界

在现有 CMCP 的连接协议和安全边界上，增加可安装、可启动的 Ubuntu 桌面客户端。首版目标为 Ubuntu 22.04 LTS、x86_64、GNOME、X11；以用户的 Ubuntu 22.04.5 / GNOME 42.9 机器作为后续真实桌面验收环境，不将 GNOME 小版本硬编码为启动条件。

保留现有 Windows / macOS 行为，不修改云端协议，不自动部署 VPS，不复用或解密另一系统的密码文件。双系统之间不要求同时运行。最初按不发布范围实现；后续按用户要求将 Linux 界面内更新和 Linux 安装包纳入 4.23.2。

## 第一阶段验收标准

1. 普通用户安装 `.deb` 后能从应用菜单启动，窗口正常显示，不要求 root 运行客户端。
2. 新增测试设备后可以连接、打开、停止、重新连接；设备之间互不影响，停止时沿用既有 CMCP 服务端退出协议。
3. 云端通过 Linux 本地工具读取临时文件、运行命令、启动 / 查询 / 停止后台进程；同样的工具调用不会落到远端 VPS。
4. 保存的密码不出现在 JSON 配置、API 返回或进程参数；密钥环锁定 / 不可用时得到明确提示。
5. SSH 使用现有主机指纹校验，不关闭 StrictHostKeyChecking，不把用户整台浏览器 / 终端结束。
6. 篡改 Host、Origin 或缺失管理令牌不能调用本地管理接口；用户自己的终端和浏览器不受退出清理影响。
7. Linux 专项测试与相关已有平台测试通过，包内包含必要运行时 / 源文件，打包过程不收集用户状态与凭据。
8. 最终报告明确区分“源码 / 测试完成”“Linux 无图形环境运行验证”“用户 Ubuntu 真实桌面验证”。后者必须在真实 Ubuntu 桌面完成后才能勾选。

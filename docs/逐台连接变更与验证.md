# 逐台连接控制：3.3.2-ui3

日期：2026-10-23。项目目录：`F:\Claude-MCP\Claude-MCP`。本目录没有 Git 元数据，本次交付为本地源码、重新编译的 EXE 与独立便携包，不涉及 WebDesktop 开发分支或 VPS 部署。

## 修复及行为

旧界面只在“打开云电脑”时传递所选名称；启动会重启共用后台并遍历所有目标，停止会关闭全部连接和自启。现在 EXE 的启动、停止、打开都必须传递所选名称，不能在未选择时调用批量分支。

每个目标独立持有连接、HTTP 代理、共享网页入口、内存中的远端认证和配置取消信号。停止 A 只取消 A 的协议检测、登录、配置和网络连接；不会调用共用 Windows 工具清理、停止 B 或重建 B 的网页登录。已提交的本机操作不具备事务回滚，停止 MCP 也不等于终止所有 Windows 程序。

本机 `target-controls.json` 仅保存名称、开关、操作版本与操作时间，不保存 Cookie、Session 或密码。命名互斥锁协调多窗口写入；同卷原子替换防止读到半份设置，Windows PowerShell 5.1 使用 `[NullString]::Value` 正确调用文件替换。目标地址修改也使用相同锁与原子写入。已连接目标重复启动保持原版本，不触发重新登录；被接管或异常结束的目标允许明确重启。

界面签发的操作时间防止延迟启动覆盖用户刚发出的停止。状态回报带操作版本，旧连接成功不会被误认作新连接成功。后台按独立槽位处理目标，离线 A 不阻塞 B；同目标未完成的创建取消后先收尾，不叠加无限创建。最多保存／处理 100 个目标，开关文件最大 256 KiB。缺失、损坏或重复标识的开关读取默认拒绝连接。

关闭界面不停止后台。逐台停止不删除共用自启项；后台可空闲运行。Windows 或后台重启只恢复已明确启用的目标，共享模式仍需要网页登录。添加地址不自动启用，修改地址保留开关。

原 BAT 保留明确批量语义：`Start-Claude-MCP.bat` 启用全部，`Stop-Claude-MCP.bat` 停止全部并清除启用开关、关闭自启。旧后台不支持逐台协议时，新界面拒绝自动重启它；用户需自行完成一次批量停止，再逐台启动新版。不得同时使用旧版界面发出批量操作。

## 文件清单

- `Claude-MCP.exe`：重编译，文件版本 3.3.2.3。
- `tools/desktop-ui/Manager.cs`：所选目标参数、请求顺序、确认文字、逐台按钮可用性、状态版本、自检。
- `tools/build-manager.ps1`：允许编译到指定输出路径，避免测试时覆盖正在使用的 EXE。
- `tools/package-manager.ps1`：ui3 独立包及新运行文件完整性检查，不覆盖 ui1/ui2。
- `app/target-controls.ps1`（新增）：有界持久开关、锁、原子写入、旧后台兼容性检查。
- `app/target-connections.mjs`（新增）：独立目标生命周期和取消，损坏开关安全关闭。
- `app/managed-target.mjs`（新增）：复用原认证、共享入口及连接核心，隔离目标的代理、配置与取消。
- `app/server.mjs`：接入逐台管理，保留共用文件工具后台；代理检查可以取消。

- `app/add-cloudpc.ps1`：提示添加后选择目标启动。
- `app/desktop-auth.mjs`：只读协议检查支持取消信号，不改变认证判定。

- `app/cloud-connector.mjs`、`app/terminal-link.mjs`：每个目标的配置 HTTP／WebSocket 与兼容准备可取消，保留原协议及安全限制。
- `app/tests/target-connections.test.mjs`（新增）：双目标真实本机网络与真实后台子进程验证。
- `app/tests/target-controls.test.ps1`（新增）：Windows PowerShell 5.1 并发写入和实际生产脚本分支验证。
- `docs/使用说明.md`、`docs/桌面版使用说明.md`、本文：逐台／批量语义、升级与验证边界。

## 人工验收与回退

重新打开根目录 EXE。选中第一台启动，完成共享网页登录；再选第二台启动并登录，确认两台状态。停止第一台后，应只失去第一台的 MCP 能力，第二台继续调用本机文件工具；再启动第一台验证恢复。反向停止第二台，重复确认。保持一台停止后重启 Windows，应仅为已启用目标准备连接／网页登录。

本轮没有操作真实 VPS、个人连接开关、密码、已有后台或自启设置。不能将上述模拟验证当作用户真实 VPS 验收。若需回退，保留的完整 ui2 便携目录／ZIP 仍在 `F:\Claude-MCP\release`；旧版界面采用批量启停，回退应由用户明确断开新版后台后进行，不要交叉启动两个版本。

# Claude 本机连接工具 使用说明

新增中文桌面入口：双击 **Claude-MCP.exe**，可统一查看连接状态、启动连接、添加云电脑、打开桌面和停止连接。首次打开界面不会自动连接；详细步骤见 **桌面版使用说明.md**。原有 BAT 入口继续保留。

目录已整理：根目录只保留 EXE 与文件夹。下文提到的所有 BAT、PowerShell 脚本、`runtime`、`node_modules` 现在均位于 `app` 文件夹；说明文档在 `docs`，构建源码和打包脚本在 `tools`。日常使用直接打开根目录的 EXE 即可。

让云电脑里的 Claude 使用您这台 Windows 电脑上的文件、命令和已安装的程序。

本分支版本：4.0.0 开发版，使用卡片式连接管理，支持备注、图标、排序、折叠详情及浅色／深色主题。设置和更新只预留禁用入口，3.3.3 的快捷方式提示继续保留。公开稳定 Release 仍为 3.3.3。

共享网页会话模式支持网页和 MCP 共用一次登录；同时保留云端要求的 Cookie 和会话编号，并在专用接口不支持共享认证时切换兼容连接。升级后需要重新运行 Start，让后台进程加载新版源码；只替换文件不会更新已运行的进程。

## 多台独立 VPS 与共享网页登录

新版 EXE 支持多台独立 VPS 同时连接本机。选择对应云电脑后，**启动连接、停止连接、打开云电脑均只作用于所选项**。停止 A 不会停止 B；每台的停止开关在电脑重启后仍然保留。下文的 BAT 是旧的批量入口，Start 启动全部，Stop 停止全部；日常逐台管理请使用根目录 EXE。

每台 VPS 自己的单会话登录约束仍然保留；它不限制另一台独立 VPS 与本机同时连接。

1. 双击 **Add-CloudPC.bat**，填写云电脑地址，密码可以留空。程序只检查登录协议，识别新版后不保存密码。
2. 双击 **Start-Claude-MCP.bat**。在自动打开的网页中输入云电脑密码；MCP 会共用这次网页登录，并自动检查 Claude 的 MCP 配置。
3. 以后从 **Open-CloudPC.bat**（打开云电脑）进入。电脑或后台服务重启后，需要再次通过这个入口登录。

网页刷新后如果再次要求密码，输入同一个密码会优先验证并复用现有会话。网络故障只重连，不会后台重新登录；会话被替换或过期时，MCP 等待你在网页中登录。

第一次切换到共享入口时，原网址的旧登录会失效一次。之后请使用共享入口；在原网址或其它设备上再次登录，仍会触发云电脑自身的单会话限制，MCP 不会自动抢回。

此模式只在本机运行代理，不修改云电脑网页服务源码。沿用原有的 MCP 连接器和兼容终端组件。

## 第一次使用

1. 把压缩包**完整解压**到一个固定文件夹，例如 `D:\Claude-MCP`。之后不要移动或删除这个文件夹。
2. 双击 **Start-Claude-MCP.bat**。
3. 在弹出的中文窗口中输入：
   - 云电脑连接地址（例如 `https://xxxx.app`）；
   - 云电脑连接密码（只包含英文字母和数字；复制粘贴时带进来的空格等字符会被自动去除）。

   点"连接"后会先检查地址，再验证密码。哪一项错了，就会在哪一项下面用红字提示，改好后再点"连接"即可。
4. 看到"连接成功"后，在云电脑上**完全退出 Claude 并重新打开一次**（只有第一次或更新后需要）。

运行所需的环境（Node.js 等）已经内置在压缩包里，不需要另外安装。

## 日常使用

- **旧版 Cookie 登录模式**：电脑开机登录后会自动在后台连接。新版共享模式请按上方步骤打开网页登录。
- 自动兼容两种云电脑：有专用直连接口时直接连接；没有该接口时，通过已登录的云电脑终端建立兼容连接，无需更新云电脑网页服务。兼容模式需要云电脑已安装 Python 3.9 或更新版本，并占用一个后台终端会话。
- 电脑离线时，云电脑上的 Claude 仍显示已连接，调用工具时会提示"本地电脑当前未连接"，电脑重新上线后直接重试即可。
- 同一时间只能有一台电脑连接同一台云电脑：另一台电脑（包括短期连接版）连上后，本机会停止连接，直到再次双击 Start-Claude-MCP.bat 或电脑重启。
- 网络或代理短暂故障时保留已有登录会话，并逐渐延长重试间隔，最长 60 秒。共享模式在会话失效后等待网页登录；旧版模式才会重新验证保存的密码。
- 如果升级时提示“旧后台服务仍在运行”，旧版可能曾以管理员权限启动。右键 Start-Claude-MCP.bat，选择“以管理员身份运行”完成这次升级。3.2.1 增加了当前账户通过停止标记请求后台退出的方式，以后不必为了停止服务反复提升权限。

## 断开连接

双击 **Stop-Claude-MCP.bat**。断开后不会再自动连接，直到再次双击 Start-Claude-MCP.bat。

## 云电脑密码修改了怎么办

- 共享模式：在通过 Open-CloudPC.bat 打开的网页中输入新密码。
- 旧版模式：后台发现密码不对，会弹出窗口请您输入新密码，验证通过后自动恢复连接。
- 双击 Start-Claude-MCP.bat 时发现密码不对，也会提示重新输入。
- 为防止云电脑被锁定，密码错误时不会反复尝试。

## 常见提示

| 提示 | 处理方法 |
|---|---|
| 地址错误 / 找不到这个地址 | 检查云电脑连接地址是否输入正确 |
| 密码错误（还可尝试 N 次） | 重新输入密码；连续错 5 次会被锁定 10 分钟 |
| 尝试次数过多 | 等待提示的时间后再试 |
| 访问密码已过期 | 联系管理员续期 |
| 已连接（兼容模式） | 已通过云电脑的登录终端连接，可以正常使用 |
| 无法加载远程桌面组件 | 浏览器未能加载软件画面组件。网络恢复后刷新共享入口网页并输入同一个密码，会优先复用已有会话；仅点软件窗口的“重新启动”可能仍保留本页的组件加载失败状态 |
| 云电脑兼容连接启动超时 | 检查云电脑是否安装 Python 3.9 或更新版本，以及终端会话是否已满 |
| 本机网络不可用 | 检查本机网络后重试 |
| 内置运行环境无法启动 | 把本文件夹加入杀毒软件的信任列表 |

## 其它

- **添加或修改云电脑**：双击 **Add-CloudPC.bat**，然后再双击 Start-Claude-MCP.bat。
- **卸载**：双击 **Uninstall-Claude-MCP.bat**，会断开连接并删除本机设置。共享模式不会为了清理云端配置另建登录；需要时，在云端 Claude 设置中手动移除 `windows-pc-files` 项。
- 设置保存在 `%LOCALAPPDATA%\ClaudeLocalMcp`，访问权限限于当前 Windows 账户和 SYSTEM。旧版密码使用 Windows 加密保存；新版密码不写入配置，会话仅保留在后台内存中。本地入口文件含临时访问密钥，请勿分享整个设置目录。
- 日志文件（在 `%LOCALAPPDATA%\ClaudeLocalMcp`）：`error.log`（启动窗口的出错详情）、`service.log`（后台连接过程）、`service-crash.log`（后台服务异常退出记录）。遇到问题时把这几个文件发给技术支持即可。

## 安全提示

连接后，云电脑上的 Claude 可以以您当前 Windows 账户的权限读写文件、运行命令和程序（不会自动获取管理员权限）。请只连接您自己的云电脑，不要把云电脑密码告诉他人。

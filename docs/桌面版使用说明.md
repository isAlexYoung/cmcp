# Claude MCP 卡片式连接管理（4.0.0 开发版）

当前分支实现新的卡片界面；公开稳定版仍为 3.3.3，尚未发布 4.0.0 Release。双击完整程序目录中的 `Claude-MCP.exe` 打开管理界面，不会自动连接。旧版 BAT 入口保留。

## 卡片操作

- 顶部右侧 **添加云电脑**：进入当前窗口中的添加页，填写备注、图标和 HTTPS 地址。共享模式可手动网页登录，也可填写密码并勾选“记住密码并自动登录”。保存时只检查共享地址和协议，不提交共享密码；保存后不会自动连接。旧版仍沿用原验证方式。
- 鼠标移入卡片显示右侧操作按钮。键盘 Tab 聚焦卡片也会显示，按钮提供中文名称和 Tooltip。
- **未连接**：点击启动该台；**连接中**／**成功连接**：点击立即请求停止此台，不再弹出确认或进度窗口。展开详情中的红色 **停止连接** 也可使用。停止时只改变所选台的开关，不终止共用后台。后台未及时确认停止时会在卡片提示，不能将请求已发送当成已经停止。
- 点击卡片空白、蓝色地址或右侧箭头只展开／收起详情。详情中的 **打开云电脑** 才打开共享网页登录入口；连接流程需要网页登录时仍会打开原有安全入口。入口未就绪、连接进度或错误都显示在卡片详情中。
- **编辑（铅笔）**：进入当前窗口中的编辑页，左上返回、右下保存。未保存时返回丢弃改动；点击保存后等待校验完成。备注和图标可单独保存；地址、密码或自动登录开关须先停止该台。已有自动密码不会回填显示：同一地址留空可保留，更换地址必须重新输入。取消勾选会删除共享模式保存的密码。
- 自定义图标支持 PNG、JPEG、ICO；原文件最多 1 MiB、2048 × 2048，规范化保存为独立 72px PNG。不加载网络图标，也不依赖原图片路径。
- **复制**：只复制这台云电脑的 HTTPS 地址，不复制 Cookie、密码或网页登录入口令牌。
- **删除**：确认后通过原有逐台停止流程停止此台，收到停止确认才删除其本地连接配置。停止超时、配置损坏或其他窗口重新启用时保留配置。不会删除 VPS、本机文件或其他目标。旧的已禁用开关记录由现有开关写入器下次清理。
- 拖动左侧六点手柄排序，移动超过 8px 后卡片跟随鼠标，其他卡片平滑让位，松开保存顺序。按 Esc 或失去鼠标捕获取消并恢复原顺序。键盘 Alt + ↑／↓ 同样可排序；排序不影响连接身份。
- 标题统一显示 **CMCP**；底部说明和链接已移除，后续再迁入设置。顶部圆形主题按钮切换 **浅色／深色**，自动保存，并同步设置支持的 Windows 标题栏颜色。设置和更新按钮明确禁用，只预留位置，不会执行自动更新。

## 数据与连接

备注、排序、图标、主题只写入当前账户 `%LOCALAPPDATA%\ClaudeLocalMcp\dashboard-preferences.json`，不修改连接协议。最多 100 项、4 MiB；损坏文件保留并提示，不静默覆盖。内部连接名保持不变，备注重名不代表同一个目标。

连接数据和 DPAPI 加密密码仍使用原位置与原格式，Cookie、Session 和网页登录入口令牌不会放入卡片偏好。支持多台独立 VPS 同时连接；关闭窗口保留连接。原 BAT Start/Stop 是批量入口，不用于逐台操作。

### 浏览器、密码与自动重连

以下为正式开发程序的行为；Preview EXE 的连接是模拟，不会打开浏览器或连接 VPS。

- 点击“未连接”后，如果后台进入等待登录，启动流程会自动打开一次该台的共享登录网页；已有有效共享会话时可直接连接。详情中的“打开云电脑”也可手动打开同一入口。
- 不要求每次打开网页都输入密码：同一台的网关和会话仍有效时继续共用。共享认证只保留在后台内存中；停止再启动该台、重启后台或 Windows、会话过期／撤销后需要重新登录。普通域名页的已有登录不等于程序共享入口已经登录。
- 普通网络断开会自动重试，间隔从约 1 秒逐步增加到最多 60 秒；有些初始化失败按既有 10 秒重试。网络恢复且会话仍有效时不重复提交密码。服务未运行时不能把“网络自动重连”理解成后台自动复活保证。
- 手动停止后保持停止；会话确认失效后等待人工网页登录；另一台电脑接管该 VPS 时停止竞争，不自动抢回。不同 VPS 的连接互不改变这些规则。

### 记住密码并自动登录

在添加／编辑页填写密码并勾选该选项，保存后启动这一台连接。程序打开的共享页面会通过原有解锁表单自动登录一次，MCP 共用同一会话；实际密码不会填入网页 DOM，也不出现在启动参数或进度。设置默认不勾选，密码使用当前 Windows 账户 DPAPI 加密保存。

密码错误、锁定或无法解密时停止自动尝试，卡片提示处理方式；刷新网页不重复尝试，可手动登录，或停止这一台后编辑密码再启动。网络重连和会话撤销不会触发再次提交密码。新登录可能使该 VPS 原先的网页桌面退出；本功能不等于复用任意已打开浏览器页面。

已有旧后台运行时，新 EXE 不会自动重启它。若卡片提示后台不支持自动登录，请在方便时手动停止旧后台，再从新版目录启动；这可能涉及全部现有连接，应自行选择切换时机。仅关闭管理窗口不会升级后台。本轮不自动执行此切换。

功能适配带标准解锁表单的共享桌面。网页结构或 CSP 不兼容时保留手动登录；不降低网页安全策略，也不绕过登录或接管保护。测试范围见 `SHARED_AUTO_LOGIN.md`。

## 安全预览

源码目录可构建 `CMCP-UI-Preview.exe`（本轮另有 `CMCP-UI-Preview-v5.exe`，避免覆盖正在打开的旧预览）：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File F:\CMCP\tools\build-manager.ps1 -PreviewOnly`。

双击该预览 EXE 只显示示例卡片，启停是模拟交互，不读取或修改真实连接数据，不运行连接脚本，不创建桌面快捷方式。主题、编辑和排序仅在预览内存中生效。打开云电脑、日志和新增目标不会在预览中访问真实系统；标题区明确显示预览说明。完整业务验证使用正式 EXE 与隔离测试，不把预览模拟算作 VPS 联机验收。

## 首次使用与快捷方式

完整解压便携 ZIP，双击正式 `Claude-MCP.exe`。保留“是否创建桌面快捷方式？”提示及“下次不再提示”选项，快捷方式名为 Claude-MCP，使用内置 Claude Desktop 图标。偏好仍位于 `manager-preferences.json`，创建失败不会压制下次提示。

第一次点击顶部“添加云电脑”保存地址，再移入对应卡片点击“未连接”。共享登录模式通过详情中的“打开云电脑”输入网页密码；首次配置后需完全退出并重新打开云端 Claude。

关闭管理窗口保留后台连接。停止的目标在后台或 Windows 重启后仍保持停止；共享模式下，已启用目标重启后仍需网页登录。BAT Start/Stop 保留全部启动／停止语义。

不自动接管不支持逐台控制的旧后台，也不为了界面升级中断现有连接。连接能力按原 Windows 用户权限执行，不要求管理员权限。

## 权限与状态

- 继续使用当前 Windows 账户的文件、命令和桌面权限；这次界面封装没有缩小或扩大原有工具能力。
- 卡片不显示密码、Cookie、Session 或本机入口密钥。添加／编辑页的旧版密码仅通过子进程输入管道传递，校验成功后沿用当前账户 DPAPI 加密保存，不放入启动参数、界面偏好或进度。原后台设置继续保存在 `%LOCALAPPDATA%\ClaudeLocalMcp`，不要分享该目录。
- 每两秒读取本地状态，并核对每台的连接开关和操作版本；不会把上一轮连接状态误作新连接成功。后台 PID 不存在、已停止或状态超过 30 秒未更新时，不显示有效连接。
- 显示“已连接”表示后台已报告成功，管理界面不会为了刷新状态主动调用 VPS。
- 连接故障、授权失效及真实工具能否运行，仍由现有连接核心和 VPS 返回决定。

## 打包与兼容

适用原项目要求的 Windows 10/11 64 位环境，使用 Windows 自带 .NET Framework 4.x/Windows PowerShell 5.1，保留内置 Node.js。**不要只复制 EXE**：它是中文管理入口，运行仍需要旁边的完整程序文件。

EXE 尚未使用商业代码签名证书。Windows 下载保护可能提示未知发布者；发布前应独立核验 ZIP 哈希及来源，不建议关闭系统安全功能。

开发者可在本机重建：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\build-manager.ps1`。

生成新的便携包：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\package-manager.ps1`。输出已存在时拒绝覆盖，需指定新输出目录；不会打包个人 LOCALAPPDATA 配置、状态、日志或凭据。

## 环境不足会自动下载吗？

**不会自动下载 Node.js，也不会自动运行 npm 安装。** 程序只使用 `app\runtime\node.exe` 与包内现有的 `app\node_modules`。缺失时连接向导报错，需重新完整解压便携包；不会改用系统 Node.js。

Windows 10/11 64 位、自带 Windows PowerShell 5.1 和 .NET Framework 4.x 是本机前提；不满足时不会自动安装系统组件。VPS 的 Python 3.9+ 也只检查、不自动安装。首次连接会上传自带 Python 连接器并注册 Claude MCP，这属于现有配置流程，不是联网下载依赖。

因此运行本工具不需要预先另外安装 Node.js，但“完整解压”和“自动修复缺失依赖”是两回事。
